# Frozen protocols and interpretation

OULAD uses J: 2013J to 2014J (AAA, BBB, DDD, EEE, FFF, GGG), and B: 2013B to 2014B (BBB, DDD, FFF). B is a retrospective independent-season check, not prospectively later than the J development analysis. Target IDs seen in any module of the corresponding full 2013 source presentation are removed; B targets also exclude J exploration IDs. Numeric features use days 0 through t; t = 7, 14, 28, 56. Labels are Fail/Withdrawn versus Pass/Distinction. The source 60/20/20 roles are learner-grouped. Roles are defined on all landmark rows. Seeds: 17, 29, 43, 59, 71. Predictor input adds course, progress and course-by-progress indicators to 46 numeric columns. LR transforms numeric features as sign(x)*log1p(abs(x)), then source-training standardizes the full design. Candidates C = 0.1 and 1 are selected by source-validation Brier. LightGBM uses 350 trees, learning rate 0.03, 7 or 15 leaves selected by the same criterion, minimum child 40, L2 5, two threads and deterministic column-wise fitting.

OULAD source OOF uses StratifiedGroupKFold, five folds, random state 1000 + seed + day. Target OOF uses five grouped folds and random state 20261001 + day + 100*(season == B), shared across predictor seeds. Platt minimizes mean logistic loss with 1e-5 penalty toward identity; slope is constrained to [0,30] and intercept to [-30,30]. Probability clipping is 1e-6. Intercept-only calibration fixes slope to one. The matched-target calibration uses three repeats and the source unique-ID budget, with exact formulas in run_primary.py. The OULAD audit summarizes 72 pair/model/landmark cells; uncertainty clusters on six code_module values, with 10,000 draws. Such small-cluster intervals remain exploratory.

XuetangX parses provider, base-course token, and offering token from exact course IDs. Consecutive offerings are sorted by first observed event, with an observed-event gap of at least seven days, >=300 enrollments per offering and >=50 in each label class. Official course calendars and original label-generation code are absent. Landmarks 7, 14, 28 are primary; 21 is a prespecified robustness landmark. Active target usernames present in the source presentation are removed in the primary protocol. Source stratified roles use 60/20/20 with the five seeds above; exact role support is checked before fitting. The action vocabulary uses only source TRAIN learners, not validation/calibration/target action counts.

XuetangX LR uses C=1, max_iter=800, lbfgs, the same signed log transform and source-training standardization. LightGBM uses up to 180 trees, learning rate 0.05, 15 leaves, depth 5, minimum child 20, L2 1, one thread, deterministic column-wise fitting and early stopping after 20 rounds on source-validation log loss. Platt is regularized toward identity with weight 1e-5, slope [0,30], intercept [-30,30]. Intercept and slope-only calibrators are additional comparisons. All probability scores clip to [1e-6,1-1e-6]. OOF has five within-offering stratified folds; one enrollment per username within an offering makes these folds learner disjoint. Exact fold seeds and target-matched resampling formulas are in primary.py and secondary_calibration.py.

DFMC is a fixed-default sensitivity, not the proposed method. Its local adapter and complete original MIT notice are in work/oulad_experiment/dfmc.py. XuetangX settings, group definitions and early stopping are in dfmc_robustness.py. Beta, isotonic, source-label-budget matched target fitting, same-course pooled history, different-earlier-course histories, earliest-to-latest pairs, zero-filled populations, matched-pair trajectories and user-assignment full refits are generated by the CLI. Their populations differ; differences across families are not treatment effects.

The target-event-rate analysis includes a foldwise target prevalence constant and target OOF intercept/Platt on exactly the same held-out target folds. Both fitted constant and OOF mappings require target outcomes. The result tests probability structure beyond a fitted constant, not prospective deployment capability. Original-label and future seven-day logged-inactivity analyses remain distinct.

Aggregation first averages available seeds within a course pair/day/model and then weights pairs equally. The primary XuetangX cluster bootstrap resamples provider-plus-base-course clusters 2,000 times, seed 20261001+100*day+(model==lightgbm). Seeds are computational repeats, not independent experimental samples. Full-pipeline cross-base-course user assignment changes both fitting and evaluated support. Refit-minus-original uncertainty uses the matched jobs and seed 20261002+11*day+(model==lightgbm). The original intervals are pointwise descriptive intervals without multiplicity adjustment; the conservative-updating analysis adds the explicitly scoped six- and 96-comparison sensitivities described below. The full original analysis retains users shared across different base courses; the user-assignment sensitivity addresses that limitation on a reduced population.

## Conservative updating and population sensitivities

The frozen `review_round2_20261011/conservative_protocol.json` payload and `work/xuetangx_experiment4/conservative_updates.py` define the count weight, historical-slope intercept fit, nested label budgets, support rules, seeds and comparison families. `work/review_round3_20261014/protocol.json` specifies the baseline, recent-active and joint-assignment populations. Implementation path names are retained for traceability.

The historical-slope intercept update fixes the fitted source slope and estimates the intercept on intermediate-presentation labels. Count-weighted shrinkage uses w = n_T1/(n_T1 + n_S_cal) to combine the historical and intermediate parameter vectors. Supported subsets require at least 10 labels and both classes; unsupported draws are not replaced. T2 labels score predictions only and do not select the strategy or shrinkage weight.

The primary future-update summaries use 100,000 course-cluster draws after averaging seeds within each sequence. Full-budget full-Platt contrasts use six-comparison intervals within each population; the wider family has 96 contrasts within each population. The separate million-draw analysis checks four tail signals only. Current common-support budget estimates and intervals are regenerated by build_evidence.py; estimates from differing support sets are not transferred into that display. Original archival-label analyses retain their stated 2,000-draw inference.

Recent-active Day 7 equals baseline on supported jobs. Joint assignment is limited to the 81-pair eligible structural course pool. These overlapping populations are sensitivities, not independent replications. All inference is conditional on fitted models and omits full-pipeline refitting uncertainty. Interpret favorable shrinkage and small-budget harm signals as exploratory.
