# Portability, provenance and redistribution

The distributed experiment scripts are copies of the manuscript's local analysis, with path handling redirected to `CALTRANSFER_ROOT` and local archive environment variables. DuckDB threads and memory are configurable. A labelled smoke mode relaxes only the original archive-size checks for a real two-offering subset. It does not alter model/calibrator settings. The final OULAD runner calls the original training and splitting functions while implementing the final decomposition without abandoned development dependencies. It was checked against saved final estimates; see validation records.

Runtime files are isolated under an explicit `--run-dir`. The repository includes no raw logs, enrollments, private IDs, fitted model caches, individual predictions, Python environments or TeX runtimes. Aggregates may contain public course identifiers and pair IDs. Code hashes for the originally executed local scripts differ from portable copies because of explicit path substitutions. `MANIFEST.json` records distribution hashes; original audit hashes describe the historical runs, not byte identity to these copies.

The entry point also computes a scientific-source manifest from reproduce.py, requirements.txt, and the Python/JSON files under work/. It pins that digest and individual source hashes in run_config.json, together with original input ZIP content hashes. Before any write, a continuation checks those fingerprints, copied runtime source and the quick/full/smoke mode. Manuscript PDFs and explanatory documentation are excluded from this scientific cache key. Existing unverified directories are never migrated silently. Completeness guards require exactly the admissible pair/day/seed/model key set, zero recorded refit failures, no duplicates and finite gains before primary/refit/future summaries can report success.

The DFMC implementation in `work/oulad_experiment/dfmc.py` is a minimal local adapter based on `src/alg/Boosting.py` in https://github.com/hjenryin/Discretization-free-MC (NeurIPS 2025). The full MIT license and copyright (c) 2025 Hongyi Jin are retained at the end of that file. No external DFMC ZIP, PyTorch setup or author notebook is required to run the paper's sensitivity. The adapter returns raw additive corrections; probability metrics use clipped copies. It is not represented as a bitwise reimplementation of the entire author repository. The sensitivity uses fixed defaults and the specific group design documented in `dfmc_robustness.py`.

Dataset terms are controlled by their publishers. The OULAD download page supplies its attribution and licensing information; the Kaggle MOOC Dataset page lists CC0. Data are not redistributed here. No repository-wide license grant is added by this distribution; third-party licenses apply only to their identified components. Third-party notices remain intact. Manuscript and figure rights are separate from dataset/code licenses.
